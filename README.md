Топ-20 признаков имеют корреляцию 0.25–0.27 с target

 2. Feature Engineering
Создали 5 новых признаков:
active_count - Количество ненулевых признаков у клиента
is_anomaly - Бинарный флаг (1 —аномалия)
row_sum - Сумма всех признаков (общий оборот)
row_mean - Среднее значение ненулевых признаков
row_std - Стандартное отклонение ненулевых признаков
