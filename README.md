Я решила исследовать датасет Mushroom Classification, потому что мне было интересно поработать с бинарной классификиацией и категориальными признаками. Также мне показался крайне интересным объект исследования, поскольку я имела опыт походов за грибами, знаю как много в интернете есть лайфхаков для определения съедобности гриба перед вами, и поэтому я посчитала это исследование имеющим практическую пользу.

Гипотезы:
1) Признак запах "odor" будет иметь ощутимую корреляцию с результатом.
2) Найдётся признак, влияние которого на результат окажется не существенным и как следствие L1 окажется полезной.
3) Метрики Accuracy и F1 будут близки по значению на наших сбалансированных данных.
4) Качество данных в этом датасете очень высокое, признаки будут хорошо разделять классы и ошибка будет крайне низкой.
5) Масштабирование не повлияет на ROC-AUC логистической регрессии с L2, так как признаки посел One-Hot Encoding будут бинарными.
6) Отбор 10 лучших признаков через SelectKBest окажет малое влияние на качество модели.


Гипотеза №1: Подтвердилась

Анализ crosstab показал, что некоторые значения признака odor дают 100% разделение классов: Запах a - 100% класс e, запахи c, f, m, p, s, y - 100% класс p, запах n - 96.6% класс e. Это один из самых сильных признаков датасета.


Гипотеза №2:  Подтвердилась

В датасете есть признаки с нулевым влиянием: veil-type имеет только одно значение, значения stalk-shape дают распределение практически 50% на 50%. LogReg с L1 показала более высокую уверенность, чем L2:
Log-Loss L1 = 0.0028
Log-Loss L2 = 0.0057
L1 увереннее, потому что она обнулила неважные признаки.


Гипотеза №3: Подтвердилась

У всех моделей Accuracy = 1.0 и F1 = 1.0. Классы в датасете сбалансированы (e: 51.8% /p: 48.2%), поэтому Accuracy не завышает оценку, и метрики совпадают.


Гипотеза №4: Подтвердилась

Все модели показали Accuracy = 1.0, F1 = 1.0, ROC-AUC = 1.0. Confusion Matrix показала 0 ошибок для всех моделей. Log-Loss близок к 0 (Decision Tree = 0.0000, L1 = 0.0028). Кросс-валидация дала CV F1 mean = 1.0, std = 0.0
Признаки действительно хорошо разделяют классы, и модели не ошибаются.


Гипотеза №5:  Подтвердилась

ROC-AUC без масштабирования: 1.0

ROC-AUC с масштабированием: 1.0

Разница: 0.0

После One-Hot Encoding признаки стали бинарными (0 или 1). Масштабирование не меняет их информативность, так как они уже в одном масштабе.


Гипотеза №6: Подтвердилась

После отбора 10 признаков через SelectKBest Accuracy и F1 снизились с 1.0 до 0.9735, что является небольшим падением. Кчаство ухудшилось, но не критично, модель всё ещё показывает высокое качество.  


Все 6 гипотез подтвердились.

Датасет Mushrooms оказался очень качественным: в нём есть признаки, которые позволяют моделям безошибочно классифицировать грибы. Все модели показали 100% точность, Confusion Matrix не содержит ошибок, кросс-валидация стабильна, масштабирование и отбор признаков не ухудшили качество. L1 регуляризация оказалась чуть увереннее L2. Данные изнчально обладали идеальной разделимостью.
